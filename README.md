# PassyTKEPackage

Binary Swift package for the Passy Apple SDK. Requires iOS 17, Mac Catalyst 17, and watchOS 10.6 or later. WatchOS excludes realtime, NFC hardware, and iBeacon ranging.

Add https://github.com/PassySRL/PassyTKEPackage.git to Xcode and select the product declared in Package.swift.
Release 0.1.8 contains the XCFramework files attached to the matching GitHub Release.
